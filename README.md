# odyssesus_journey

## Task 1 :  Finding the Sea Floor

I focused on data preprocessing and visualization, leaning on my machine learning experience to prioritize Exploratory Data Analysis (EDA) and  outlier removing methods. To get the dataset clean, I used an Exponentially Weighted Moving Average (EWMA) for smoothing; I considered a Kalman Filter but ultimately decided it was too complex for the problem(and lack of information). For the visualizations I created a ax subplot and used legends , labelling of axis title and a grid and made the overall style of the graph into a visual of a radar system ,  and used funcAnimation to create the the depth-time graph I used AI to help navigate and debug the code for the animated graphs.

## Task 2 :  Keeping Watch Over Odysseus

Now the circuit building and programming challenge. I started with first laying down the components on the tinkercad.I choose LCD_I2C instead of LCD due to is requirement of pins and in-built potentiometer. I relied on AI to help navigate the complexities of the LCD interface setup, while I focused on the coding logic like creating a blinking led function and researching component functions to manage the system state properly.There are some difficulties during the circuit connection where the previous resistor connection was ineffective Hardware engineering is outside my comfortzone and expertise, but navigating those technical hurdles to get a fully functional system running was a certainly a challenge.
