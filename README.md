# odyssesus_journey

## Task 1
I focused on data preprocessing and visualization, leaning on my machine learning experience to prioritize Exploratory Data Analysis (EDA) and  outlier removing methods. To get the dataset clean, I used an Exponentially Weighted Moving Average (EWMA) for smoothing; I considered a Kalman Filter but ultimately decided it was too complex for the problem(and lack of information). For the visualizations, I used AI to help naviagte and debug the code for the animated graphs.
